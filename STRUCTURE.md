## Contracts

| Contract | Responsibility | Key params (`contracts/config/params.json`) |
|---|---|---|
| `IndexFactory` | `createAndBuy`, ticker registry, visibility, mode at creation | `creationFeeUsdc` 5, `minFirstBuyUsdc` 100, `minAssets` 2, `maxAssets` 20, `minWeightBps` 100 |
| `IndexVault` | ERC-20 units, buy / sell / redeem(forfeit), holds basket | `tradeFeeBps` 50, `deadUnits` 0.01, `startLevel` 100 |
| `PriceOracle` | pushed prices, maxAge, bands, optional Chainlink | per-asset from generated assets file |
| `FeeSplitter` | protocol / creator split, creator claim | `protocolBps` 30, `creatorBps` 20 |
| `Rebalancer` | modes, versions, drift/interval trigger, plans, auctions, guards | `noticeSec` 172800, `modeChangeDelaySec` 172800, `driftBps` default 5000 (1000–20000), `intervalSec` 2592000, `dailyCapBps` 500, `lossBudgetBps` 100, `maxDurationSec` 1209600, `premiumBps` 50, `floorBps` 200, `auctionSec` 2700, `lotCapBps` 100 |
| `IndexLens` | read views for app, indexer, tests | — |
| `StockVenue` + `PToken` | synthetic stock legs (spec §6) | `spreadBps` 15, `reserveRatioBps` 15000, `seedReserveUsdc` 5000000, caps from assets |
| `TokenVenue` | contest token legs at oracle ± spread | `spreadBps` from assets |
| `DexVenue` | production token legs via pool paths | fork-tested only |
| `SwapRouter` | asset → asset swaps | `swapFeeBps` 10, `treasury` |

Demo config may shorten `noticeSec` / `modeChangeDelaySec` (e.g. 600) for Fuji demos; production
values stay as above.

## TypeScript packages

Each has `README.md` (≤ 10 lines), `package.json`, `tsconfig.json`, `src/index.ts`, `src/config.ts`
(reads `PANTADO_PROFILE` + `config/*`), `test/` (vitest), `Dockerfile` (services and keepers).

| Path | Depends on | Exposes |
|---|---|---|
| `packages/shared` | — | loaders, schemas, types, `basketMath`, `venueQuote` |
| `packages/sdk` | shared | ABIs, reads, tx builders |
| `keepers/*` | shared, sdk | long-running loops with `/health` + metrics |
| `services/indexer` | shared, sdk | Postgres tables (spec §9.2) |
| `services/market-data` | shared | `price:*` Redis keys, `prices` pub/sub, `/internal/prices` |
| `services/api` | shared, sdk | public REST + WS (spec §9.7) |
| `services/agent` | shared (HTTP to api only) | `/ask` SSE, `/draft`, `/assessment/:index`, manager loop |
| `apps/web` | shared, sdk, api | UI |

Service-to-service calls go over HTTP/Redis only — no service imports another service's code.

## Config

- `config/assets.json` — spec §4. Generated files are never edited by hand.
- `config/networks/<profile>.json` — `{ data, execution, venues, priceSource, flags }`.
- `config/services.json` — indexer, marketData, api, presets, agent, keepers, monitoring.
- `contracts/config/params.json` — contract parameters (table above).
- `.env` — secrets only. See `.env.example`.

## Naming

- Asset ids: lowercase symbol without dots (`nvda`, `btcb`, `wethe`, `wavax`, `usdc`). pTokens: name
  "Pantado <Name>", symbol `p<SYMBOL>`.
- Index ids `idx-<ticker lowercase>`. Plan ids `plan-<idx>-<n>`, auction ids `auc-<idx>-<n>`.
- DB `snake_case`; Redis `<area>:<chain>:<id>`; WS channels `prices`, `trades:<assetId>`,
  `level:<indexId>`, `auctions`.
- REST plural nouns, kebab-case; JSON camelCase. Env vars UPPER_SNAKE with owner prefix (`API_`,
  `INDEXER_`, `AGENT_`, `KEEPER_`, `NEXT_PUBLIC_`).
- Solidity tests `*.t.sol`; TS `*.test.ts`; Playwright `*.spec.ts`.

## Architecture phases

| Phase | Scope | Gate |
|---|---|---|
| P1 | Root workspace, `packages/shared`, `scripts/gen-config.ts`, `contracts/` skeleton + `params.json` | loaders + generated files validate; `forge build` green |
| P2 | Core contracts: factory, vault, oracle, fee splitter, lens, test tokens, `TokenVenue` | unit + fuzz + invariant tests green (level math, pro-rata, redeem never blocked, stale → revert) |
| P3 | `Rebalancer` (modes, versions, Auto trigger, auctions, guards) | tests for every guard and mode transition; Anvil scenario: shock → plan → fills → drift reduced |
| P4 | `StockVenue` + `PToken`, `SwapRouter`, `Deploy.s.sol`, `Demo.s.sol`, `packages/sdk` | all forge tests green; Anvil demo end to end; deployments file written |
| P5 | Keepers: price-pusher, auction-filler, rebalance-trigger, auto-fund | keeper tests green; Anvil run keeps prices fresh 30 min |
| P6 | `services/indexer`, `market-data`, `api` (+ quotes, presets, search), `scripts/check-level.ts` | level check passes; quote golden tests match forge fixtures |
| P7 | `apps/web` port of the reference UI on real API/SDK, Privy | Playwright smoke on Anvil (every screen; buy, sell, redeem, create) |
| P8 | `services/agent` | tool tests with recorded fixtures; draft validation; manager dry-run |
| P9 | `infra/*`, Fuji deploy, monitoring, `test/e2e-app` acceptance (spec §14) | acceptance green on Fuji |
| P10 (optional) | `DexVenue` on an Avalanche mainnet fork | fork tests green |
